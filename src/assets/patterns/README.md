# Card patterns

Background patterns from [Hero Patterns](https://heropatterns.com/) by Steve Schoger,
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Retrieved
2026-10-20 from the `hero-patterns` npm package (2.1.0).

Changes: the fill is set to white at full opacity; `PlayerCard` sets each pattern's
strength. The player cards give each team slot one pattern so cards are easier to tell apart.
